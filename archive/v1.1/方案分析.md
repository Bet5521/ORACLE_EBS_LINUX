# Oracle EBS 兼容方案 - 技术分析

## 问题本质

Oracle EBS → Java Applet (NPAPI) → 浏览器 → JRE 6u7+ → x86/ARM硬件

## 浏览器NPAPI支持矩阵

| 浏览器 | NPAPI支持 | 版本范围 | 推荐 |
|--------|----------|---------|------|
| Firefox 52 ESR | ✅ | 52.0 ~ 52.9.0 | ⭐⭐⭐⭐⭐ |
| Pale Moon | ✅ | 全部版本 | ⭐⭐⭐⭐ |
| SeaMonkey | ✅ | 2.53+ | ⭐⭐⭐ |
| Firefox ESR (新) | ❌ | ≥ 57 | 不可用 |
| Chrome/Chromium | ❌ | ≥ 45 | 不可用 |

## Oracle JRE插件文件位置

- 32位: `${JRE_HOME}/lib/i386/libnpjp2.so`
- 64位: `${JRE_HOME}/lib/amd64/libnpjp2.so`

浏览器搜索路径: `~/.mozilla/plugins/libnpjp2.so`, `/usr/lib/mozilla/plugins/libnpjp2.so`

## ARM64模拟方案

1. QEMU全系统VM（推荐内存≥4GB）
2. QEMU用户模式+proot
3. Box64+Wine
4. Docker+QEMU
5. Box86（备选）
