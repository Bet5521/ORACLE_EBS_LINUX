# Oracle EBS 兼容方案 - 技术分析

## 问题本质

```
Oracle EBS → Java Applet (NPAPI) → 浏览器 → JRE 6u7+ → x86/ARM硬件
```

**核心矛盾：**
- JRE 6u7~8 是 x86 架构
- ARM64 无法原生运行 x86 JRE
- 现代浏览器已移除 NPAPI 插件支持

## 浏览器NPAPI支持情况

| 浏览器 | NPAPI支持 | 版本 | 推荐 |
|--------|----------|------|------|
| Firefox ESR | ✅ | ≤ 52 | ⭐⭐⭐⭐⭐ |
| Pale Moon | ✅ | 最新版 | ⭐⭐⭐⭐ |
| SeaMonkey | ✅ | 2.53+ | ⭐⭐⭐ |
| Chrome | ❌ | 45+ | 不可用 |
| Edge | ❌ | 全版本 | 不可用 |

## JRE版本策略

```
JRE 6u7 ─→ 直接使用
JRE 7/8 ─→ Java控制面板 → 安全 → 站点例外
```
