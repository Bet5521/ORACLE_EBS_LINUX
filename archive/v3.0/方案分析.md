# Oracle EBS 兼容方案 V3.0 技术分析


## 关键技术决策

### 1. 为何仅 Firefox 52 ESR？
- Firefox 57+ 已移除 NPAPI（Quantum 引擎）
- Firefox ESR 最新版 ≥ 115 也移除了 NPAPI
- Firefox 52 ESR 是最后支持 NPAPI 的官方版本

### 2. 为何仅 OpenJDK 8？
- IcedTea-Web（OpenJDK 的 Java Web Start 实现）要求 Java 8
- IcedTea-Web 不兼容 Java 11+
- OpenJDK 11/17 无法加载 Java Applet

### 3. Oracle JRE vs OpenJDK
| 维度 | Oracle JRE | OpenJDK 8 + IcedTea |
|------|-----------|---------------------|
| 兼容性 | 最好 | 好 |
| 安装方式 | 手动下载 | 包管理器 |
| NPAPI插件 | 自带 | IcedTea-Web提供 |
| 推荐场景 | 正式生产 | 快速试用 |

### 4. ARM64 模拟策略
- QEMU 全系统 VM（最稳定，内存≥4GB）
- QEMU 用户模式 + proot（轻量）
- Box64 + Wine（技术探索）

## 插件文件

```
Oracle JRE: ${JRE_HOME}/lib/amd64/libnpjp2.so
OpenJDK 8:  /usr/lib/jvm/java-8-openjdk-*/jre/lib/amd64/libnpjp2.so
```

浏览器搜索路径: `~/.mozilla/plugins/libnpjp2.so`
