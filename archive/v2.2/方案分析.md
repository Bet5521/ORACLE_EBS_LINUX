# Oracle EBS 兼容方案 V2.2 技术分析

## Java 运行环境双路径

### 路径A: Oracle JRE
- 手动下载 Oracle JRE 8/7/6u7
- 兼容性最好
- 需手动安装

### 路径B: OpenJDK 8 + IcedTea
- 包管理器自动安装
- `apt install openjdk-8-jdk icedtea-plugin`
- IcedTea 提供 NPAPI 插件

**为何仅 OpenJDK 8？**
- IcedTea-Web 最低要求 Java 8
- IcedTea-Web 不兼容 Java 11+
- OpenJDK 11/17 无法加载 Java Applet

## 浏览器NPAPI支持

| 浏览器 | NPAPI | 版本 |
|--------|-------|------|
| Firefox 52 ESR | ✅ | 52.x |
| Pale Moon | ✅ | 全部 |
| SeaMonkey | ✅ | 2.53+ |
| Firefox ESR | ❌ | ≥ 57 |
| Chrome | ❌ | ≥ 45 |

## IcedTea 插件路径

```
${JAVA_HOME}/jre/lib/amd64/libnpjp2.so
${JAVA_HOME}/jre/lib/i386/libnpjp2.so
/usr/lib/jvm/java-8-openjdk-*/jre/lib/*/libnpjp2.so
```
